PS ESTIMATING STATIC WEBSITE
=============================

Included:
- index.html
- about.html
- services.html
- contact.html
- css/style.css
- js/script.js
- assets/favicon.svg

HOW TO RUN
----------
Open index.html in a browser.

HOW TO DEPLOY TO NETLIFY
------------------------
1. Create a free Netlify account.
2. Drag the project folder/ZIP into Netlify's deploy area, or connect a GitHub repository.
3. Netlify gives you a temporary *.netlify.app address.
4. In Netlify: Domain management -> Add a domain.
5. Add your own domain and follow the DNS instructions.

IMPORTANT
---------
The demo uses remote Unsplash images for generic construction imagery.
Replace those image URLs with your client's own licensed images for the final website.
The phone, email, address, logo and text should also be changed to the client's real details if this is for another company.

CONTACT FORM
------------
The demo contact form uses mailto as a no-backend fallback. For a professional live site, use Netlify Forms or a small PHP/serverless endpoint so messages are delivered reliably.

The layout is an original static implementation inspired by the supplied screenshot/site structure; it is not a dump of the original site's source code or proprietary assets.
